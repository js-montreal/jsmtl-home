## Git Usage Rules
* ALWAYS ask for permission before deleting, merging or pushing branches to remote.
* Before starting _any_ work in this repo, always check first what branch you're on.
    * If you're on main, branch out to a feature branch and work there.
    * If already on a branch, ask me first if you should branch out or continue working on the current branch.
* If there are untracked files that you didn't create, leave them alone! I'll tell you explicitly
if I want them included in commits.

## Development Rules
* The website is deployed to Github Pages, so keep in mind that we don't have a backend.
* JS and CSS code belongs in separate files. DO NOT embed it directly in HTML.
* Write code yourself as much as possible. If you feel that a feature is sufficiently complex to warrant
using a library or framework, ask for my permission first and explain why the lib/framework would be a better
choice.
* Always check your work in a browser, especially if the changes are visual. Don't forget to check how it looks in a mobile-sized viewport!
* Write the minimal amount of code necessary to achieve your goal. Think very carefully before modifying
unrelated code. Changes that make new (and old) code cleaner, better, more readable are ok, but refactoring
or cleaning up just because is NOT ok.
